Statistical Independence — Contingency Tables & χ² Test

Programmatic Bivariate Cross-Tabulation (X, Y), Joint / Marginal / Conditional Distributions, Expected Frequencies Eij, Pearson's χ² & p-Value, and Association vs. Causality

Section 1 — Theoretical Concepts of Independence in Probability & Statistics Measure-Theoretic Events vs. Bivariate Empirical Contingency Tables

1. Probabilistic Independence of Events & Random Variables: On a probability space (Ω, ℱ, ℙ), two events A, B ∈ ℱ are statistically independent (written A ⊥⊥ B) if and only if their joint probability factorizes into the product of their marginal probabilities:

ℙ(A ∩ B) = ℙ(A) · ℙ(B) ⇔ ℙ(A | B) = ℙ(A) (for ℙ(B) > 0) ⇔ ℙ(B | A) = ℙ(B) (for ℙ(A) > 0)

For two discrete categorical random variables X ∈ {x1, …, xR} and Y ∈ {y1, …, yC} (denoted (X, Y) or (X, F) in bivariate feature notation), let pij = ℙ(X = xi, Y = yj) be the joint probability mass function, with row marginals pi• = Σj=1..C pij and column marginals p•j = Σi=1..R pij. Then X and Y are independent (X ⊥⊥ Y) if and only if:

p_{ij} = p_{i•} · p_{•j} for all i ∈ {1, …, R}, j ∈ {1, …, C}

Equivalently, every conditional distribution of Y given X = xi is invariant across rows and identical to the marginal distribution of Y:

p_{Y|X}(y_j | x_i) = p_{ij} / p_{i•} = p_{•j} and p_{X|Y}(x_i | y_j) = p_{ij} / p_{•j} = p_{i•}

2. Empirical Contingency Table & Expected Frequencies under H0: Given a sample {(Xk, Yk)}k=1..N of size N, let Oij = nij be the observed count in cell (i, j), with row marginal totals ni• = Σj nij, column marginal totals n•j = Σi nij, and grand total N = Σi,j nij. Under the null hypothesis of statistical independence H0 : pij = pi•p•j, replacing unknown marginals with their maximum likelihood estimators p̂i• = ni• / N and p̂•j = n•j / N yields the expected frequency in cell (i, j):

E_{ij} = N · p̂_{i•} · p̂_{•j} = (n_{i•} · n_{•j}) / N

3. Pearson's Chi-Square Statistic, Degrees of Freedom & p-Value: To quantify the global discrepancy between observed counts Oij and independence expectations Eij, Karl Pearson (1900) introduced the test statistic:

χ² = Σ_{i=1..R} Σ_{j=1..C} (O_{ij} − E_{ij})² / E_{ij} = Σ_{i,j} r_{ij}², where r_{ij} = (O_{ij} − E_{ij}) / √E_{ij} ( standardized Pearson residual )

By Cochran's theorem and the multivariate Central Limit Theorem, under H0 (as N → ∞, with Cochran's rule of thumb requiring Eij ≥ 5 in at least 80% of cells and all Eij ≥ 1), the statistic χ² converges in distribution to a Chi-square distribution with df = (R − 1)(C − 1) degrees of freedom (since estimating R + C marginals subject to Σi p̂i• = 1 and Σj p̂•j = 1 leaves (RC − 1) − (R − 1) − (C − 1) = (R − 1)(C − 1) free parameters). The asymptotic upper-tail p-value and normalized effect sizes (Cramér's V and Contingency Coefficient C) are:

p-value = ℙ(χ²_{df} ≥ χ²_{obs}) = 1 − P(df/2, χ²_{obs}/2) = Q(df/2, χ²_{obs}/2) Cramér's V = √( χ² / (N · min(R − 1, C − 1)) ) ∈ [0, 1], Pearson's C = √( χ² / (χ² + N) )

Section 5 — Reference Programmatic Implementation Single-Pass Cross-Tabulation, Expected Frequencies, χ² Statistic & Exact Incomplete Gamma p-Value 
// 1. Construct contingency table, marginals, conditionals, E_ij, and Chi-square from any bivariate dataset (X, Y)
function analyzeContingency(pairs) {
  const rowSet = new Set(), colSet = new Set();
  for (const [x, y, w = 1] of pairs) { rowSet.add(String(x)); colSet.add(String(y)); }
  const rows = Array.from(rowSet), cols = Array.from(colSet);
  const R = rows.length, C = cols.length;
  const rIdx = Object.fromEntries(rows.map((r, i) => [r, i]));
  const cIdx = Object.fromEntries(cols.map((c, j) => [c, j]));

  // Observed frequency matrix O_ij and marginal totals n_{i.}, n_{.j}, N
  const O = Array.from({ length: R }, () => new Float64Array(C));
  const rowTotals = new Float64Array(R), colTotals = new Float64Array(C);
  let N = 0;
  for (const [x, y, w = 1] of pairs) {
    const i = rIdx[String(x)], j = cIdx[String(y)];
    O[i][j] += w; rowTotals[i] += w; colTotals[j] += w; N += w;
  }

  // Marginal relative frequencies: f_{i.} = n_{i.}/N, f_{.j} = n_{.j}/N
  const rowMarginals = rowTotals.map(r => r / N);
  const colMarginals = colTotals.map(c => c / N);

  // Expected frequencies under independence E_ij = (n_{i.} * n_{.j}) / N, conditional frequencies, and Chi-square
  let chi2 = 0, g2 = 0;
  const E = Array.from({ length: R }, () => new Float64Array(C));
  const jointRel = Array.from({ length: R }, () => new Float64Array(C));
  const condGivenRow = Array.from({ length: R }, () => new Float64Array(C)); // P(Y = y_j | X = x_i)
  const condGivenCol = Array.from({ length: R }, () => new Float64Array(C)); // P(X = x_i | Y = y_j)

  for (let i = 0; i < R; i++) {
    for (let j = 0; j < C; j++) {
      E[i][j] = (rowTotals[i] * colTotals[j]) / N;
      jointRel[i][j] = O[i][j] / N;
      condGivenRow[i][j] = rowTotals[i] > 0 ? O[i][j] / rowTotals[i] : 0;
      condGivenCol[i][j] = colTotals[j] > 0 ? O[i][j] / colTotals[j] : 0;
      if (E[i][j] > 0) {
        const diff = O[i][j] - E[i][j];
        chi2 += (diff * diff) / E[i][j];
        if (O[i][j] > 0) g2 += 2 * O[i][j] * Math.log(O[i][j] / E[i][j]);
      }
    }
  }

  const df = (R - 1) * (C - 1);
  const pValue = df > 0 ? regularizedGammaQ(df / 2, chi2 / 2) : 1.0; // Upper-tail P(Chi2_df >= chi2)
  return { rows, cols, N, O, E, rowTotals, colTotals, rowMarginals, colMarginals, jointRel, condGivenRow, condGivenCol, chi2, g2, df, pValue };
}
Section 6 — Discussion: Interpreting Independence Tests & Distinguishing Association from Causality Symmetry of χ², Structural vs. Sampling Zeros, Confounding, and Pearl's Ladder of Causation

1. Interpreting the Statistical Decision (Rejecting vs. Failing to Reject H0): A small p-value (p < α, equivalently χ²obs > χ²1−α, df) indicates that the observed deviations (Oij − Eij) are too large to be plausibly explained by random sampling variation alone under H0 : X ⊥⊥ Y; we therefore conclude that X and Y are statistically dependent (associated). Conversely, when p ≥ α, we fail to reject H0: the empirical conditional distributions P̂(Y | X = xi) are statistically indistinguishable from the marginal distribution P̂(Y), which is consistent with independence (though in small samples one must also verify statistical power via Cramér's V).

2. Why Statistical Dependence Does Not Imply Causality: The Pearson χ² statistic is algebraically symmetric in X and Y: transposing the contingency table leaves Oij, Eij, df, and χ² completely unchanged. Consequently, a contingency table alone can only measure observational association ℙ(Y | X = x) ≠ ℙ(Y), whereas a causal effect concerns an active intervention do(X := x) in Judea Pearl's structural causal framework:

Statistical Association: ℙ(Y = y | X = x) ≠ ℙ(Y = y) (Seeing / Conditioning on X) Causal Effect (Intervention): ℙ(Y = y | do(X := x)) ≠ ℙ(Y = y) (Doing / Manipulating X)
Structural Mechanism DAG Representation Observational Test (X ⊥⊥ Y?) Causal Effect X → Y? Concrete Illustration
Direct / Indirect Causation X → Y or X → M → Y Dependent (χ² large, p ≪ α) Yes (ℙ(Y | do(X)) varies) Enforcing Hardware FIDO2 MFA (X) directly blocks credential-stuffing intrusions (Y).
Reverse Causation X ← Y Dependent (χ² identical to X → Y) No (Y causes X) Emergency incident response deployment (X) is triggered by a detected breach (Y).
Common Cause (Confounding) X ← Z → Y Marginally Dependent (X ¬⊥⊥ Y), but X ⊥⊥ Y | Z No (Spurious association) Summer temperature (Z) drives both Ice Cream Sales (X) and Swimming/Drowning (Y).
Collider Bias (Selection) X → S ← Y (conditioned on S = 1) Conditionally Dependent given S = 1, even if X ⊥⊥ Y No (Berkson's paradox) Among reported high-profile incidents (S = 1), exploit sophistication (X) and target value (Y) appear negatively correlated.
Summary Takeaway (Simpson's Paradox & Causal Identification): Even a highly significant χ² test (p < 10−12) and a large Cramér's V only establish that knowing X improves our statistical prediction of Y in the observed population. Establishing that X causes Y requires either (i) a Randomized Controlled Trial (RCT) where random assignment severs all incoming confounding arrows into X so that ℙ(Y | do(X = x)) = ℙ(Y | X = x), or (ii)measuring and stratifying on a sufficient back-door adjustment set Z (via the Mantel–Haenszel test or log-linear models) to eliminate confounding and guard against Simpson's paradox.
